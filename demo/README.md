# 시연 실행 안내

## 준비 (한 번)
1. Pleos Connect 에뮬레이터(v2.1.0 이상)를 실행하고 앱을 설치합니다: `./gradlew installDebug`
2. 위치와 차량 속도 권한을 허용합니다. AAOS의 현재 운전자는 사용자 10번입니다.
   `adb shell pm grant --user 10 com.example.hyundai_contest android.permission.ACCESS_FINE_LOCATION`
   `adb shell pm grant --user 10 com.example.hyundai_contest android.permission.ACCESS_BACKGROUND_LOCATION`
   `adb shell pm grant --user 10 com.example.hyundai_contest android.car.permission.CAR_SPEED`
   (앱을 처음 열 때 뜨는 권한 창에서 허용해도 됩니다. 차량 속도 권한이 없으면 GPS 속도로 대신합니다.)
   앱은 부팅(시동)하면 앱을 열지 않아도 코칭을 시작합니다. 두 번째 권한(위치 "항상 허용")이 있어야 그때도 GPS를 받습니다.
   설치 직후나 강제 종료 뒤에는 앱을 한 번 열어야 부팅 자동 시작이 동작합니다(안드로이드 규칙).
3. 앱을 실행하고 제목 **"초보운전 코치"를 길게 눌러** 시연 패널을 엽니다 → **12주 데모 기록 불러오기**

## 시연 순서 (설계 문서 6장)
시연 전용 화면은 없습니다. 모든 장면이 실제 앱 화면입니다.

| 모듈 | 하는 일 |
|---|---|
| 1 실시간 코칭 | `powershell -ExecutionPolicy Bypass -File demo\demo.ps1` 실행, Enter로 단계 진행. 기어를 D에 놓는 순간 앱이 실시간 코칭 화면으로 바뀝니다. 깜빡이 없이 빠르게 회전(주황 2건) → 깜빡이 켜고 회전(초록) → 깜빡이 켜둔 채 직진(음성 코칭) → 상향등 켜둔 채 주행(30초 뒤 음성 코칭) |
| 2 주차·하차 코칭 | 스크립트의 "시연 2" 단계. D단에서 문 열림 → 후진 주차(빠른 후진 음성, 덜 멈춘 변속 1번, 기어 변경 3번) → 창문 연 채 하차. 모두 음성 코칭. P단에 놓는 순간 화면이 주행 요약으로 바뀝니다 |
| 3 주행 코칭 | **주행 코칭** 탭에서 방금 주행의 요약과 "다음 주행에서 해볼 것" |
| 4 성장 기록 | **성장 기록** 탭: 깜빡이 제때 켠 비율과 주차 기어 변경 횟수의 12주 변화 |
| 5 자주 놓치는 곳 | **자주 놓치는 곳** 탭: 시청 사거리 핀 |

`-Auto`를 붙이면 Enter를 기다리지 않고 끝까지 진행합니다(리허설·녹화용).

## 알아둘 점
- **스크립트를 돌리는 동안에는 Virtual Console 브라우저 탭을 닫아 주세요.** 스크립트는 차량 속도를 콘솔로 넣는데, 콘솔 페이지가 열려 있으면 페이지 안의 주행 시뮬레이션(가속·관성)이 그 속도를 덮어써서 감지가 어긋납니다. 탭이 열려 있으면 스크립트가 안내를 띄우고 닫힐 때까지 기다립니다.
- 위치는 에뮬레이터 GPS(`adb emu geo fix`)로, 속도는 콘솔의 차량 속도로 넣습니다. 앱 화면은 달리는 동안에도 보입니다.
- 안전벨트는 에뮬레이터에서 값을 바꿀 수 없어 시연에 없습니다. 12주 데모 기록에만 들어 있습니다.
- 후진 기어에서는 차량 기본 후방 카메라가 화면을 덮습니다. 그동안의 코칭은 음성으로 나갑니다.
- 콘솔은 브라우저 세션 하트비트가 3초 안에 갱신되지 않으면 입력을 거부합니다. 스크립트가 하트비트를 자동으로 보냅니다.
- 에뮬레이터에서도 Pleos 온디바이스 TTS로 음성이 나옵니다(PC 스피커). 로캘은 국가까지 넣은 `ko_KR`로 지정해야 합니다. 언어만 넣은 `ko`는 엔진이 "unsupported locale"로 거부합니다. 말한 문장은 `adb logcat -s Coach`의 `announce:` 줄로도 확인할 수 있습니다.
- 주차 음성의 "평소 N번"은 기기에 쌓인 최근 주차 10번의 평균입니다. 데모 기록을 불러온 상태에서는 평균이 2번 안팎이라 "평소는 2번이에요"로 나오고, 기록이 없으면 비교 없이 횟수만 말합니다.
